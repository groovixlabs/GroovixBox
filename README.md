# GroovixBox

GrooviBox is an extendable performance controller based on Teensy 4.1. 

                    
This project is the open firmware for the controller. You can build your own Midi Controller,  synthesizer, DAW surface , Digital Mixer or DMX controller etc using the hardware.

Hardware is Modular with one breakout board with Teensy 4.1 connecting to the Encoder , Keys and LED boards.

Featuring 

16 rotary encoders with buttons.
16 LED rings with 13 Level LEDs and 3 RGB Status LEDs for each encoder. 
32 Swappable Cherry switches.
32 RGB Key Status LEDs
3 Shift Keys.
LCD display.
USB Host
USB Device Mode.
3 MIDI In , 3 MIDI Out (1 in&out with 5 pin DIN)
SPDIF to connect to DAC to build sytnths.
